# Gmail/Calendar tutorial — Video Part B (of 2): using the client from Python via an AI agent

> Source: Dr. Yoram Segal, course 203.3763 "Orchestration of AI Agents", HW6 (EX06) Moodle materials.
> Part B demonstrates driving the OAuth client from Python: prompting an AI coding agent (he uses
> Codex/GPT-5; Claude/Gemini work too) to build a **uv**-based test program that mints the **token**
> (first run → browser consent for the test user) and then performs an action — in the demo, writing a
> Gmail **draft** and adding a Google **Calendar** event 4 hours out. Client + token are stored together
> **outside** the project. For HW6 we use the **Gmail send** half (a JSON report email at game end);
> Calendar / email-reading shown here is the tutorial's generic example, not a HW6 requirement.

עכשיו אתם יכולים בעצם לבצע את המשימה עם הסוכנים. עכשיו אתם אמורים לבנות את הסוכן שלכם, שבעצם הולך, קורא את המיילים, עובר עליהם, מוצא זימון לפגישה ובעצם מוסיף את הפגישה פה. אתם זוכרים שאתם צריכים, כמובן תצטרכו לשלוח לעצמכם אימייל, אתם יכולים ממש מעצמכם לשלוח לעצמכם, זה גם בסדר. אתם יכולים לשלוח מבחוץ ואז לראות שקיבלתם את המייל ובאמת מתווספת הפגישה. תודה רבה ובהצלחה.
